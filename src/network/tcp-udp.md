# TCP 与 UDP 对比

## TCP (传输控制协议)

- **面向连接**：三次握手建立连接
- **可靠传输**：确认机制、重传机制
- **拥塞控制**：慢启动、拥塞避免、快速重传
- **全双工**：双向通信
- **首部**：20-60 字节

### 三次握手

```
客户端 ── SYN=1, seq=x ──→ 服务器
客户端 ←── SYN=1, ACK=x+1 ── 服务器
客户端 ── ACK=y+1 ──→ 服务器
```

### 四次挥手

```
客户端 ── FIN=1 ──→ 服务器
客户端 ←── ACK ── 服务器
客户端 ←── FIN=1 ── 服务器
客户端 ── ACK ──→ 服务器
```

## UDP (用户数据报协议)

- **无连接**：不需要建立连接
- **不可靠**：没有确认和重传
- **高效**：首部仅 8 字节
- **支持广播/多播**

## 适用场景

| TCP | UDP |
|-----|-----|
| HTTP/HTTPS | DNS |
| FTP | DHCP |
| SSH | VoIP |
| Email | 视频流 |
| 文件传输 | 实时游戏 |

## 常见状态

```
LISTEN      - 监听中
ESTABLISHED - 连接已建立
TIME_WAIT   - 等待关闭
CLOSE_WAIT  - 等待关闭
SYN_SENT    - 同步已发送
SYN_RECV    - 同步已接收
```
