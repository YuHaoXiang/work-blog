# 互联网定义

> 互联网是一个 **分布式应用进程** + **基础设施**

| 组成部分 | 包含内容 |
|---------|---------|
| 分布式应用进程 | HTTP、DNS、FTP、SSH、SMTP 等各种网络协议和服务 |
| 基础设施 | 物理网络 (路由器、交换机、光纤)、TCP/IP 协议栈、网卡、操作系统网络层 |

**核心原理**：应用程序通过协议进行通信，基础设施负责数据传输。

```
互联网 ≈ (应用程序 + 协议) + (物理设备 + 传输介质)
        ↑                           ↑
     分布式进程                   基础设施
```
